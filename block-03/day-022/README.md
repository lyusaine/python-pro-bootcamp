# Build Pong Arcade Game
## Process
- Create a Paddle that responds to Key Presses.
- Make a Paddle Class and create the second paddle.
- Make the Ball Class and make the ball move.
- Add the Ball bouncing logic.
- Detect collisions with the paddle.
- Detect when ball goes out of bounds.
- Score tracking and changing the ball speed.
